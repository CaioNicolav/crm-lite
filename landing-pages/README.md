# Páginas de captação — HTML salvo do navegador

Os arquivos `revendedor.html` e `distribuidor.html` preservam o código HTML exportado das duas páginas originais, seus formulários e referências de assets externos.

**Alterações mínimas de segurança na publicação:**
- Tokens OAuth encontrados nas capturas HTML foram removidos.
- Nonces temporários de formulário foram substituídos por marcadores.
- Endereços de caixa de contato foram substituídos por um endereço de exemplo.

A renderização local pode depender de elementos carregados do WordPress original. Esses arquivos são evidência técnica de implementação, não um pacote WordPress instalável e não devem ser usados para receber leads.
